# Сервис прогнозирования кассовых разрывов для малого бизнеса

Прототип аналитического дашборда, разработанный для кейса Банка «Центр-Инвест». 
Сервис анализирует историю транзакций, прогнозирует остаток на счете на 30 дней вперед и предупреждает предпринимателя о рисках кассовых разрывов.

## Стек
* Python 3
* Streamlit (UI)
* Pandas, Numpy (обработка данных)
* Prophet / Scikit-learn (прогнозирование)
* Plotly (визуализация)

## Архитектура
* `app.py` — точка входа, интерфейс Streamlit.
* `src/data_loader.py` — ETL-модуль: загрузка CSV, очистка данных (фикс ИНН, форматирование дат).
* `src/categorizer.py` — модуль автоматической категоризации операций по назначению платежа.
* `src/forecaster.py` — ML-модуль прогнозирования остатка.
* `src/risk_engine.py` — модуль поиска аномалий и кассовых разрывов.

## Запуск локально
1. Установите зависимости: `pip install -r requirements.txt`
2. Запустите приложение: `streamlit run app.py`

## Реализованные фичи
* Загрузка и парсинг банковских выписок.
* График прогноза баланса с выделением зон риска.
* Сценарии «Что если» (задержка оплаты, внеплановые расходы).
* Аналитика по контрагентам и категориям расходов.

## Данные для тестирования
Полный датасет (150 компаний, 222 тыс. операций) не включен в репозиторий из-за ограничений GitHub на размер файлов. 
Для быстрого запуска и проверки работоспособности в папке `sample_data/` лежит выписка одной компании (C001.csv). 
В интерфейсе приложения вы можете загрузить любой другой CSV-файл из выданного датасета через кнопку "Загрузить выписку".
